Concept Questions:

===================================

CSS ka full form kya hai?
Ans: Cascading Style Sheet.

===================================

CSS kya hai?
Ans: CSS is a styling language.

===================================

CSS ka main purpose kya hai?
Ans: Main purpose of CSS is add style on webpage.

===================================

Kya CSS ek programming language hai? Agar nahi, to kya hai?
Ans: CSS programming language nahi hai, wo ek styling language hai.

===================================

HTML aur CSS mein kya difference hai?
Ans: Html website stucture banane ka liya hai aur CSS website ko style karna ka liya hai.

===================================

JavaScript aur CSS mein kya difference hai?
Ans: JavaScript website interactivity add karna ka liya hai aur CSS website ko style karna ka liya hai.

===================================

Ek webpage banane mein HTML, CSS aur JavaScript ka role kya hota hai?
Ans: Html built webpage stucture, CSS add style on stucture and JavaScript add interactivity on stucture.

===================================

CSS kin 5 cheezon ko style kar sakti hai?
Ans: fonts, image, button, background color and font color.

===================================

Agar CSS na ho to webpage kaisa dikhega?
Ans: Plain text, no color etc.
===================================

Har modern website CSS kyun use karti hai?
Ans: To make website beautiful.
